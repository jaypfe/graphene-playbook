# GrapheneOS Playbook

How I set up and run [GrapheneOS](https://grapheneos.org/) on my everyday phone:
the security settings I use, the apps I picked to fill the gaps, sandboxed
Google Play, two numbers on one phone, spam call filtering and backups.

A [BeboSec](https://bebosec.com/) project. The write-up of why I made these
choices is on the blog:
[My GrapheneOS Setup](https://bebosec.com/posts/my-grapheneos-setup/).

**Start here: [SETUP.md](SETUP.md)**, the whole setup from install to backup,
in order. Each step links to the detail below.

| Doc | What's in it |
| --- | --- |
| [Setup guide](SETUP.md) | Start to finish, in order |
| [Apps](docs/apps.md) | My core apps and the ones worth recommending: where to get them and how I set them up |
| [Sandboxed Google Play](docs/google-play.md) | Installing it and the settings I lock down |
| [Settings](docs/settings.md) | Lock screen, network and home-screen settings |
| [Two numbers](docs/two-numbers.md) | A second (public) number on an eSIM |
| [Spam calls](docs/spam-calls.md) | SpamBlocker setup and testing |
| [Backups](docs/backups.md) | Seedvault, Aegis, Signal, and restoring |
| [Checks and maintenance](docs/maintenance.md) | What to check after setup, updates, and fixes |

These are my choices, not official GrapheneOS guidance. For installing and
anything GrapheneOS-specific, the [official docs](https://grapheneos.org/usage)
are the source of truth. Keep your own PINs, recovery codes and account details
out of any copy of this repo.
